# 麦当口述 · AI 味 / 公式反例

写完对照删。出现则默认重写开头或整段。

| 反例 | 问题 | 改成 |
|------|------|------|
| 「你有没有想过……」 | 他自己点名的冗余万能钩 | 直接说判断 / 结果画面 |
| 「你有没有遇到过这种情况——」 | 早期公式痛点开场 | 直抒胸臆或真实结果 |
| 「最近 XX 很火，但是装起来很麻烦……」 | 千篇一律痛点切入 | 已经发生的结果钩进去 |
| 「今天给大家介绍一款产品……」 | 产品介绍体，秒划走 | 观点立住后再让产品当证据 |
| 「在这个 AI 快速发展的时代……」 | 时代背景垫场 | 删掉，从命题开始 |
| 「我今天讲这个，不是为了 A，而是为了 B」 | 模型对称转折 | 直接说观察和判断 |
| 「本质上 / 说白了 / 真正重要的是……」连用 | 路标堆砌 | 靠场景和因果接 |
| 观点文写成「第一点第二点第三点」目录 | 教程骨架盖过观点 | 判断→为什么→会怎样 |
| 结尾「记得点赞关注转发，我们下期再见！加油！」 | 口号 CTA | 一句锚点判断 + 轻 CTA + 签名 |
| AI 单独开一章灌概念 | 硬塞 | AI 必须是叙事视角本身 |
| 冒充亲测 / 编造第一手经历 | 人机红线 | 标明未实测或留空 |
| 全文「我们」带练腔（非用户要求） | 不像他原生口述 | 默认改回「我」 |
