# 麦当口述风格（content-script-local-draft）

把麦当怎么说话、怎么抛观点，收成可执行的 Agent Skill。  
**商单 / 教程 / 开源发布是用法，不是人格。** 不抄卡兹克长文法庭体。

默认人称：**我**。完整口径：[`references/mdldm-oral-style.md`](references/mdldm-oral-style.md)。  
范例：[`references/style_examples.md`](references/style_examples.md)。  
反例：[`references/ai-anti-examples.md`](references/ai-anti-examples.md)。

---

## 何时用

使用：

- 口述 / 观点 / 口播整理或重写；
- 脚本大纲、观点型正文、非教程型商单；
- 封面标题与多平台发布素材；
- 用户要「像麦当」「别 GPT 味」「直抒胸臆」。

不用：

- 只聊抽象营销理论、不产出文稿；
- 纯剪辑 / 纯设计 / 纯平台点击发布且不要文案；
- 一句无关紧要的润色且用户不要风格约束。

---

## 模式路由

| 模式 | 触发 | 先读 |
|------|------|------|
| **口述 / 观点（默认）** | 口播、观点、个人判断、非教程商单 | `mdldm-oral-style.md` + `style_examples.md` |
| **商单可选** | 明确品牌合作、产品演示、甲方 brief | 同上，并启用「产品是证据」；教程型才加重步骤 |
| **发布包** | 发布素材、封面、多平台文案 | 口述正文已立住后再做；观点型仍读 oral-style |

用户只要大纲或首批草稿：按阶段交付，不擅自扩成完整发布包。

---

## 核心硬规则（摘要）

1. **开头直判 / 结果画面**；硬禁「你有没有想过 / 遇到过」等万能开场（除非原话如此）。
2. **判断 → 为什么 → 会怎样**；不先上课程目录。
3. **人称默认「我」**；「我们」仅带练。
4. **不编造第一手经历**；缺测标明留空。
5. **产品是证据不是菜名**；适合谁 / 不适合谁。
6. **结尾锚点 + 轻 CTA + 签名**；不喊口号。
7. **AI 融进叙事**；删掉 AI 段落后若仍成立，说明 AI 是硬塞的。

写任何观点 / 口播正文前，必须打开 oral-style 与 style_examples；写完对照 ai-anti-examples 与下方质检。

## 标准流程（口述优先）

### Step 0：读原料

1. 当次口播 / 观点 / brief（原话优先）；
2. `references/mdldm-oral-style.md` + `style_examples.md`；
3. 同目录 1—2 份成熟成稿（若有）；
4. 用户当次修正覆盖旧习惯。

原始口播未落库且要迭代：先存只读源，正文另存版本。

### Step 1：还原判断与事实

抽出：

- 真正要下的一句判断；
- 可公开的具体场景 / 数字 / 边界；
- 哪些是亲测、哪些是官方演示、哪些待验证；
- 若有产品：它证明判断的哪一句。

不要先套发布模板，不要先写封面。

### Step 2：写口述正文（默认交付重心）

按 oral-style：

- 第一句直达命题或结果画面；
- 因果链推进；
- 商单模式再嵌入 2—3 个产品证据动作；
- 结尾锚点 + 轻 CTA + 签名变体择一。

### Step 3：质检（必须）

**L1 硬禁（命中则重写）**

- [ ] 「你有没有想过 / 遇到过」等万能开场；
- [ ] 「今天给大家介绍一款产品」介绍体开场；
- [ ] 时代背景垫场（快速发展的时代……）；
- [ ] 结尾口号堆砌 / 多冲突外链硬广；
- [ ] 编造未提供的第一手经历或假亲测；
- [ ] 观点文被写成第一步第二步目录（用户未要求教程时）。

**L2 口述清单（缺一项则补）**

- [ ] 有一句可独立传播的判断；
- [ ] 至少一个具体场景或数字；
- [ ] 人称默认「我」；
- [ ] 念出声顺口；删半形容词仍成立；
- [ ] 若有产品：删掉品牌名后观点仍成立；
- [ ] 对照 `ai-anti-examples.md` 无连续模型套话。

### Step 4：封面与平台（仅当用户要发布包 / 标题时）

口述正文过质检后再做。

**封面**

- 一张封面一个承诺；主标题 + 可选一角标；
- 点击三问：和谁有关 / 点开得到什么 / 哪个结果驱动点击；
- 反目录：多步骤、多功能、多案例同时出现 ≥2 项则删；
- 强结果必须有正文证据；不保证赚钱涨粉。

**平台**

- B 站：完整说明 + 真实时间轴（有成片才写，不编）；
- 抖音 / 视频号：前三秒一个强事实或强判断；
- 小红书：独立文案，不复制 B 站简介；Skill 挂载时主 CTA 单一；
- 社群 / 动态：像本人预告，不统一广告腔。

### Step 5：落盘

- 优先写与原稿相邻的本地 Markdown；
- 不覆盖原始口播源；
- 回报路径、主判断句、主推封面（若有）。

---

## 商单可选模式（短规）

用户明确商单时：

1. 仍先写得立住的观点或结果画面；
2. 产品从「这套逻辑我正好在……上看到了」类入口进，不品牌冷开场；
3. 2—3 个证据动作 + 适合谁 / 不适合谁；
4. 教程型商单才展开可复用步骤 / 提示词；
5. 过同一套 L1 / L2。

---

## 封面点击示例（保留）

不推荐：`别急着录课 / 博主知识变现先走这 7 步`（目录感）  
推荐：`怎么靠知识赚到第一笔钱？` + 角标 `免费开源 Skill`

不推荐：`某某工具全功能深度测评`  
推荐：用户能完成的具体任务 / 省下的成本。

## 最终验证

### 口述

- [ ] 已读 oral-style 与 style_examples；
- [ ] L1 全过、L2 全过；
- [ ] 主判断句可单独拿出去；
- [ ] 无假亲测。

### 发布包（若需要）

- [ ] 封面一个承诺；小红书独立；
- [ ] CTA 不冲突；无保证赚钱涨粉；
- [ ] 已写入本地且未覆盖源稿。
