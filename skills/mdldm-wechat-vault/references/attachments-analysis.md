# 后续附件和 AI 分析模块

本版已独立实现消息解密与查询，未实现媒体提取或模型调用。图片、语音、视频和表情显示明确占位；不表示已看到媒体内容。

附件模块应单独建立资源表、消息资源关联表及派生结果表，支持一对多/多对一。资源保留来源、文件哈希、原图/缩略图状态、提取状态与错误；图片数据库解密和图片 .dat 解码不是同一个能力。语音先核实本地版本存储布局，再提取、解码和转写。

文件实体放 accounts/账号/attachments；转写、OCR 和描述放 derived，不能覆盖原始资源。分析模块只接收用户选定素材，不访问 key 或任意 DB。

本包没有网络模型请求。若由当前 Agent 总结，材料按当前模型服务的处理方式流转，不能宣称所有 AI 分析都离线。未来模型 local/cloud 路由必须显式配置并预览输入范围。
