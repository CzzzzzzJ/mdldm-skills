# 麦当剪辑口播

把我剪口播的那套习惯写成了一个 Agent Skill：录屏 + 真人讲解的视频，丢给 Agent，按麦当的路子一条龙剪完。

粗剪 → 术语校对 → 高对比单行字幕 → 开头先甩成果 → 全屏讲解板 → 顶部章节进度条 → 知识站软导流 → 片尾真实网页截图信息卡 → 轻松 BGM → 简介文案 → 局部打码。

---

## 适合谁

- 做 **AI 工具评测、操作教程、案例演示** 的人
- 素材是 **屏幕录制 + 口播讲解**，内容通常是：介绍工具 / 模型 → 演示几个任务 → 展示成果 → 给资料入口
- 想要一个稳定的剪辑口径，不想每次都从头跟 Agent 解释怎么剪

这是剪辑方法，不是固定模板。片长、曲目、时间点每次按你当次的要求来。

---

## 先装

```bash
npx skills add CzzzzzzJ/mdldm-skills --skill maidang-koubo
```

或把本目录整份拷进 Agent 的 skills 目录。剪辑本身靠你当前环境里的编辑能力（剪辑软件 / 剪辑 Agent），Skill 管的是"怎么剪"。

---

## 怎么用

1. 把工程、主录屏、成果视频、截图、成播稿（有的话）都放好
2. 跟 Agent 说一句"麦当剪辑口播"，或者"沿用麦当口播流程"
3. 它先看时间线、比例、帧率、已有剪辑和字幕，再按顺序干活；你只想改一项，就只说那一项

触发语示例：

```text
麦当剪辑口播，把这条录屏粗剪一下，字幕做成高对比单行。
沿用麦当口播流程，讲理论的地方做全屏讲解板，我划词的地方让出来。
沿用麦当口播流程，开头把三个成果先弹出来，片尾做 GitHub 和 Hugging Face 的信息卡。
只做局部打码：把提示词里跟任务无关的那句遮掉，录屏缩放时也要跟住。
```

---

## 它会干什么

| 步骤 | 做法 |
|------|------|
| 1. 粗剪 | 去重复论述、重录、口误、"嗯啊呃"，删超过 0.5 秒的无信息气口；保住"任务—操作—结果—评价"这条线，不把结论剪反 |
| 2. 术语校对 | 对照声音、录屏文字、成播稿和官方资料核模型名、团队名、参数；分清是识别错还是我本人说错 |
| 3. 字幕 | 单行粗体、和背景高反差（白底录屏用黑底白字）、按短语切；清掉剪辑接缝的残字；模型名、英文、数字单位不拆开；避开人物和演示重点 |
| 4. 开头成果 | 口播提到哪个结果，就在那个点弹真实成果预览；开头没点名成果时，用后半段最硬的结果在钩子处预告；用录屏定格截图，关掉素材自带声音 |
| 5. 全屏讲解板 | 讲理论、画面静止时整屏换成图文讲解板，人像留在原位置的窗口里；**我划词、操作页面和口播对应时，讲解板让开露出录屏** |
| 6. 章节进度条 | 贴顶跟着播放走，按内容分章节，当前章节高亮，后面还有啥一眼看到 |
| 7. 知识站软导流 | 开头身份牌、讲解板署名、结尾名片卡；不放网址、二维码、引导词，避免被判引流 |
| 8. 片尾信息卡 | 打开真实网页截图，**截图嵌进同一张 MG 信息卡**；画面里不露 URL、地址栏、二维码 |
| 9. BGM | 直接用现成曲库，轻松、无人声、铺满全片，淡入淡出，压在人声下面；非商用许可的要在简介署名 |
| 10. 简介文案 | 标题备选、简介、和进度条一致的章节时间轴、配乐署名、话题标签 |
| 11. 局部打码 | 只遮那一句，不盖整屏；录屏缩放、滚动时遮挡跟着走 |

---

## 输出长啥样

- 一条剪好的时间线：逻辑完整、高对比单行字幕、开头成果预览、全屏讲解板、顶部章节进度条、知识站软露出、片尾 MG 信息卡、全片低音量 BGM、该遮的都遮住
- 一份发布用简介文案
- 一段简短交付说明：实际改了什么，哪些画面看过、哪些声音试听过、哪些还没验证

不会默认导出、发布，也不会顺手改你没让动的东西。
