# 测试指南

在独立运行环境中执行：

```bash
python -m unittest discover -s tests -v
```

## 自动测试范围

测试使用 SQLite 生成的合成数据库和独立测试加密器，覆盖：

- 页面解密、密钥验证和 SQLite 查询。
- 已提交 WAL 重放、未提交尾部处理及校验字节序。
- 错误密钥、篡改数据和损坏日志的拒绝行为。
- 源数据变化或缺少密钥时停止发布，保留旧快照。
- 时间边界、分页、精确会话查询及账号绑定。
- 核心流程无需外部微信工具即可执行。

## 真实环境验收

自动测试不覆盖 macOS 进程授权、客户端登录和实际微信版本的全部兼容性。当前版本的真实微信端到端兼容性仍待验证。

验收时使用本人账号和不含隐私的测试消息，依次检查：

1. 密钥捕获及所选数据库覆盖。
2. 正常退出微信后的快照生成。
3. 消息正文、会话、发送时间与客户端记录一致。
4. 新增消息后的快照刷新与查询。
5. 多分库、分页及错误状态的正确处理。

记录系统版本、微信版本、数据库配置和失败环节；不要在测试报告中包含密钥或私聊内容。
